# Panchayat Grievance Register and Resolution Tracker – Frontend

##Description
This repository contains the frontend of the **Panchayat Grievance Register and Resolution Tracker**, a web application designed to simplify grievance management in local governance.

The application enables citizens to register complaints, track the status of their grievances, and receive updates. It also provides Panchayat officials with an intuitive dashboard to review, manage, assign, and resolve complaints efficiently.

##Features
- User Authentication
- Citizen Grievance Registration
- Complaint Status Tracking
- Category-wise Grievance Management
- Official Dashboard
- Responsive User Interface
- Real-time Status Updates

## Tech Stack
- JavaScript (ES6+)
- HTML5
- CSS3

##Objective

To provide a transparent, efficient, and user-friendly platform for managing Panchayat grievances, improving communication between citizens and local authorities.
